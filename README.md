# Análise de Polaridades e Emoções em Avaliações de Aplicativos

Trabalho acadêmico de Processamento de Linguagem Natural (PLN) do curso de Análise e Desenvolvimento de Sistemas do IFSP São Carlos.

## Objetivo

Construir um corpus de avaliações da Google Play Store em português brasileiro e utilizar técnicas tradicionais de PLN para classificar a polaridade dos textos e investigar as emoções expressas.

## Proposta

- Coletar e preservar as avaliações em seu formato textual original.
- Explorar o corpus e comparar técnicas de pré-processamento, incluindo stemming.
- Experimentar representações Bag of Words e TF-IDF.
- Comparar classificadores tradicionais com um baseline.
- Investigar emoções utilizando um léxico emocional.
- Avaliar os resultados e discutir erros, vieses e limitações.

As estrelas serão utilizadas como um indicador aproximado de polaridade, sujeito a divergências com o texto. A análise de emoções será independente das notas.

## Tecnologias previstas

- Python
- Google Colab / Jupyter Notebook
- Git e GitHub

As bibliotecas e suas versões serão documentadas conforme forem adotadas.
